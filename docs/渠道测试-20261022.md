# 渠道测试记录（2026-10-22）

测试方式：只读探测，每个渠道尝试取 10 条；结果写入本文件，不导入产品库。测试目标是确认“能不能稳定拿到 10 条”，不是做全量采集。

## 一、ATS 公开 API

| 渠道 | 结果 | 说明 |
|---|---|---|
| Greenhouse | 10 条 | Anthropic board，`/v1/boards/anthropic/jobs` |
| Ashby | 10 条 | OpenAI board，`/posting-api/job-board/openai` |
| Lever | 10 条 | `leverdemo` board，`/v0/postings/leverdemo` |
| Workable | API 200，样本 0 | `stripe`/`shopify` 返回空 jobs，需要换有效 company token |
| SmartRecruiters | API 200，样本 0 | `Visa`/`Bosch` 返回 0，需要有效 company id |
| Recruitee | 406 | `recruitee.com/api/offers/` 被拒绝，需具体子域和正确 Accept |

## 六、结论

- **稳定拿到 10 条**：Greenhouse、Ashby、Lever、Remotive、HN、AIHOT RSS。
- **API 可达但样本 0**：Workable、SmartRecruiters；需要有效 company token。
- **明确阻塞**：Recruitee 406、GDELT 429、Google News 超时、RemoteOK SSL。
- **需登录/解析**：微博/知乎、国内官网/飞书、Boss/猎聘/智联、LinkedIn/Indeed。
- 不能把“未测/0 条”写成“已接入”；下一步先补有效 token 和国内页面解析。
