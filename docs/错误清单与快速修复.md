# 最近报错清单与快速修复（2026-10-22）

## 1. 高频“假报错”：PowerShell 把原生 stderr 当异常

现象：Node/Edge 往 stderr 写警告，PowerShell 显示 `NativeCommandError` 或 `[exit code: 1]`，但命令实际成功。

快速修复：
- 不要把 `2>&1` 直接接 `Select-Object`；改成 `*> file.log`，再看文件。
- 用 `$LASTEXITCODE` 判断真实退出码；`NativeCommandError` 不等于失败。
- 例：`& node app.js *> out.log; "exit=$LASTEXITCODE"`。

## 2. 中文乱码 / UnicodeEncodeError

现象：控制台 GBK 编码，打印中文/emoji 报 `UnicodeEncodeError`，或输出变成 `����`。

快速修复：
- Python 脚本开头 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`。
- PowerShell：`[Console]::OutputEncoding=[Text.UTF8Encoding]::new()`。
- 更稳：脚本把结果写 UTF-8 文件，用 `read` 读文件，不依赖控制台。
- 新采集器已加 `--json-out`，统计写文件。

## 3. 模型 JSON 带 ``` 围栏 / 截断

现象：`json.loads` 报 `Expecting value: line 1 column 1`。

快速修复：
- 先剥 ```json 围栏，再 `json.loads`。
- 保存原始输出到文件；解析失败时先看原始文本，不要重发请求。
- 批量太大时拆小批（100–150 条/批）。

## 4. SQLite 表结构/字段错误

现象：`ambiguous column name`、`no such column`、`记录含未声明字段`。

快速修复：
- 所有 join 字段加表别名（`r.title`、`f.name`）。
- 先 `PRAGMA table_info(...)` 看真实列，再改 SQL。
- 导入白名单要同步新增字段（本次 `views` 就漏过）。
- 迁移用 `ALTER TABLE ... ADD COLUMN`，不要改旧库结构。

## 5. 网络 SSL / 超时

现象：Ashby/Perplexity 偶发 `SSL: UNEXPECTED_EOF_WHILE_READING`、timeout。

快速修复：
- 采集器已做 3 次重试 + 退避；单家失败不拖垮全局。
- 失败记入 `failed`，下次重跑；ATS 写入是幂等 upsert，重跑不会重复。
- 不要因为一次 SSL 失败就改代码。

## 6. `gh` 未安装

现象：`gh : 无法将“gh”项识别为 cmdlet`。

快速修复：
- 改用 GitHub REST API（`https://api.github.com/search/repositories?q=...`）。
- 或先 `winget install GitHub.cli`，但本次不需要。

## 7. 工具调用中断/结果未知

现象：`The tool call was interrupted ... outcome unknown`。

快速修复：
- 先查 DB/文件确认有没有副作用，再决定是否重跑。
- ATS 用 `UNIQUE(source,external_id)` + upsert，重跑安全。
- 不要盲目重放有删除/覆盖的脚本。

## 8. 正则替换重复渲染

现象：一次替换把同一段 24 行插入了多遍。

快速修复：
- 用“整段 section 替换”，不要对每个子元素做无锚点全局替换。
- 替换后统计关键行出现次数（如 `class="hrow"` 应为 24）。

## 9. `robocopy` 退出码 1

`robocopy` 的 1 表示“复制成功”，不是失败。判断看目标文件数量/哈希。
